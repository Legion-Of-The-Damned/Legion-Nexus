# Legion Nexus Launcher

## Системные требования
- Windows 10/11 (64-bit)
- 4GB+ RAM
- 500MB свободного места

## Установка

### Вариант 1: Портативная версия
1. Скачайте LegionNexus_Launcher.zip
2. Распакуйте в любую папку
3. Запустите LegionNexus.exe

### Вариант 2: Установщик
1. Скачайте LegionNexus_Setup.exe
2. Запустите установщик
3. Следуйте инструкциям

## Первый запуск
1. При первом запуске может потребоваться установка Java
2. Нажмите "Установить Java 8" в настройках
3. После установки Java можно запускать игру

## Настройка
- Выберите папку для Minecraft (можно оставить стандартную)
- Настройте количество ОЗУ
- Выберите разрешение экрана
- Укажите никнейм
- При желании добавьте скин

## Устранение проблем
- Если игра не запускается - проверьте установку Java
- При проблемах с правами - запустите от имени администратора
